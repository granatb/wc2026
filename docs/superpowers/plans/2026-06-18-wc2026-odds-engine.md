# wc2026 Odds Engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace hand-estimated team lambdas with market-derived probabilities (incl. player props) blended per-game with expert research, on the existing shared Monte Carlo substrate.

**Architecture:** Pure-math core (`blend`, `odds_math`) is network-free and TDD'd first → it produces working, verifiable software immediately. Live API clients (`odds`, `schedule_api`) sit behind a local JSON cache so the engine runs offline once data is fetched. A research loader merges markdown overrides per the blend rules. Engine + game models consume blended numbers; YOLO switches to a ceiling objective.

**Tech Stack:** Python 3, stdlib only for math/engine; `urllib`/`requests` for API clients; `pytest` (fallback `unittest`) for tests. The Odds API + api-football for live data. No third-party numerics required.

**Spec:** `docs/superpowers/specs/2026-06-18-wc2026-odds-engine-design.md`

**Note:** not a git repo — "commit" steps are aspirational; if `git init` is run later they apply. Tests are the verification gate regardless.

```python
# core/blend.py
"""Odds x expert blend math. w=0 -> pure odds, w=1 -> full expert overlay.
Hard facts (out/suspended) are absolute and ignore w."""

HARD_OUT_STATUSES = {"out", "suspended"}

def blend_lambda(lam_odds: float, *, multiplier: float, w: float) -> float:
    return lam_odds * (1 + w * (multiplier - 1))

def blend_rate(rate_odds: float, *, expert: float, w: float) -> float:
    return (1 - w) * rate_odds + w * expert

def apply_status(status: str | None, *, base_rate: float, base_start: float, w: float):
    if status in HARD_OUT_STATUSES:
        return 0.0, 0.0
    return base_rate, base_start
```

```python
# core/odds_math.py
"""Pure odds math: de-vig, lambda solving, prop->rate. No network."""
import math

def implied_probs(decimal_odds):
    return [1.0 / o for o in decimal_odds]

def devig(decimal_odds):
    raw = implied_probs(decimal_odds)
    s = sum(raw)
    return [r / s for r in raw]
```

- [ ] **Step 3: Implement** (grid Poisson + coarse-to-fine search over λ pair minimising 1X2 error; cap goals at 8).

```python
def _pois(k, lam):
    return math.exp(-lam) * lam**k / math.factorial(k)

def poisson_1x2(lh, la, max_goals=8):
    pH = pD = pA = 0.0
    for h in range(max_goals + 1):
        for a in range(max_goals + 1):
            p = _pois(h, lh) * _pois(a, la)
            if h > a: pH += p
            elif h == a: pD += p
            else: pA += p
    return pH, pD, pA

def solve_lambdas(pH, pD, pA, lo=0.2, hi=3.5, steps=34, refine=3):
    best, lh0, la0 = 1e9, 1.2, 1.2
    span = (lo, hi, lo, hi)
    for _ in range(refine):
        lo_h, hi_h, lo_a, hi_a = span
        gh = [lo_h + (hi_h-lo_h)*i/steps for i in range(steps+1)]
        ga = [lo_a + (hi_a-lo_a)*i/steps for i in range(steps+1)]
        for lh in gh:
            for la in ga:
                qH, qD, qA = poisson_1x2(lh, la)
                err = (qH-pH)**2 + (qD-pD)**2 + (qA-pA)**2
                if err < best:
                    best, lh0, la0 = err, lh, la
        d = (hi-lo)/steps
        span = (lh0-d, lh0+d, la0-d, la0+d)
    return lh0, la0
```

```python
def scorer_prob_to_goal_rate(p_anytime):
    if p_anytime <= 0: return 0.0
    if p_anytime >= 1: p_anytime = 0.999
    return -math.log(1 - p_anytime)
```
